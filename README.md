# 🤖 DOGUINHA STORE BOT

Bot de WhatsApp para venda de assinaturas premium com PIX automático via Mercado Pago.

---

## 📱 COMO CRIAR O BOT PELO CELULAR

### 1. CRIAR REPOSITÓRIO NO GITHUB
- Acesse: github.com
- Clique em **"+"** e **"New repository"**
- Nome: `doguinha-store-bot`
- Deixe como **Público**
- Clique em **"Create repository"**

### 2. FAZER UPLOAD DOS ARQUIVOS
- No repositório criado, clique em **"uploading an existing file"**
- Arraste todos os arquivos do bot
- Clique em **"Commit changes"**

### 3. CONFIGURAR NO RENDER
- Acesse: render.com
- Clique em **"New +"** e **"Web Service"**
- Conecte sua conta do GitHub
- Selecione o repositório `doguinha-store-bot`
- Preencha:
  - **Name:** doguinha-store-bot
  - **Runtime:** Node
  - **Build Command:** `npm install`
  - **Start Command:** `npm start`
  - **Plano:** Free

### 4. CONFIGURAR VARIÁVEIS DE AMBIENTE
- No Render, aba **"Environment"**
- Adicione todas as variáveis do arquivo `.env`

### 5. INICIAR O BOT
- Clique em **"Create Web Service"**
- O bot vai iniciar automaticamente
- Nos logs, aparecerá um **QR Code**
- Escaneie com o WhatsApp do bot

### 6. PRONTO!
- O bot está online 24/7
- Acesse o painel admin enviando qualquer mensagem do seu número
